# 🔐 Análise de Vulnerabilidades com Nmap e Nessus

## 📌 Descrição
Este projeto tem como objetivo realizar uma análise de vulnerabilidades em um ambiente controlado utilizando ferramentas de segurança amplamente utilizadas no mercado.

## 🛠️ Ferramentas utilizadas
- Nmap
- Nessus

## 🔎 Atividades realizadas
- Varredura de rede
- Identificação de hosts ativos
- Detecção de portas abertas
- Identificação de serviços em execução
- Análise de vulnerabilidades
